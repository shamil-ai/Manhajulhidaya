# Manhajul Hidaya Da'wa Campus - Web Portal

A fully functional static web portal and admission management system built for Manhajul Hidaya Da'wa Campus. 

## 🌟 Key Features
* **Student Admission System:** Complete registration form with profile photo upload.
* **Email Notifications:** Integrated with EmailJS to send confirmation emails to applicants automatically.
* **Candidate Dashboard:** Secure login for registered students to view their profile and access digital ID cards.
* **Admin Console:** Password-protected admin panel to manage admissions, view contact messages, and export data as CSV/Excel.
* **Serverless Architecture:** Designed to run seamlessly on GitHub Pages without a traditional backend database.
